# C++ 学习笔记

[中文](README.md) | [English](README-English.md)

一个按课程顺序整理的 C++ 学习笔记仓库，内容覆盖 C++ 入门、面向对象、内存管理、模板和 STL 容器。笔记主要用于系统学习、复习核心概念和建立可持续扩展的 C++ 知识结构。

## 学习路线

```text
C++ 基础
   ↓
类和对象
   ↓
内存管理
   ↓
模板
   ↓
STL 简介
   ↓
string / vector / list / stack / queue
   ↓
模板进阶
```

建议先掌握语言基础和类的基本使用，再学习对象生命周期、资源管理和模板。完成 STL 容器部分后，应重点练习“能用、明理、能扩展”三个层次：先会使用接口，再理解底层结构，最后尝试实现或扩展组件。

## 知识重点

### C++ 基础

- 了解 C++ 从 C 语言发展而来的背景，以及标准化和版本演进。
- 理解 C++ 语言、标准库和 STL 之间的关系。
- 建立查阅标准文档和库接口文档的习惯。

### 类和对象

- 使用 `class` 定义数据和行为。
- 理解封装、访问控制和成员函数。
- 掌握构造函数、析构函数、拷贝构造和赋值运算符。
- 理解编译器生成的默认成员函数，以及何时需要手动实现。
- 使用初始化列表正确初始化引用、`const` 成员和没有默认构造函数的成员对象。

### 内存管理

- 区分栈、堆、静态区、常量区和代码区。
- 理解动态内存分配、释放和扩容。
- 区分 C 风格的 `malloc/free` 与 C++ 风格的 `new/delete`。
- 关注内存泄漏、悬空指针、重复释放和越界访问等问题。

### 模板与泛型编程

- 使用函数模板和类模板编写类型无关的代码。
- 理解模板实例化和参数推导。
- 学习非类型模板参数、模板特化和偏特化。
- 在复用性、可读性和编译复杂度之间进行权衡。

### STL 与容器

- 理解容器、迭代器、算法和函数对象等 STL 组件之间的关系。
- 掌握 `string` 的字符串管理和常用操作。
- 理解 `vector` 的连续存储、`size`、`capacity`、`resize` 和 `reserve`。
- 理解 `list` 的节点结构、迭代器和插入删除特点。
- 使用 `stack` 和 `queue` 解决后进先出、先进先出等问题。

## 学习建议

1. 先通读课件，建立每个主题的概念地图。
2. 对每个接口同时记录用途、复杂度、前置条件和失效规则。
3. 不只记忆 STL 接口，尝试理解容器的底层数据结构。
4. 将课件中的代码片段改写成独立的小实验。
5. 对涉及资源管理的代码，重点检查对象生命周期和异常路径。
6. 学习模板时同时关注类型推导、实例化结果和编译错误信息。
7. 用标准文档核对接口细节，不把单个编译器的行为当成语言标准。

## 通用编译方式

仓库当前以课件资料为主。如果后续添加 `.cpp` 示例，可以使用支持 C++11 或更高标准的编译器：

```bash
g++ -std=c++11 -Wall -Wextra -Wpedantic example.cpp -o example
```

对于使用较新语言特性的代码，可以将标准切换为：

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic example.cpp -o example
```

Windows 环境可以使用 MinGW-w64、Visual Studio 或其他支持现代 C++ 标准的工具链。
